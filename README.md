# JARVIS for Windows

Локальный ИИ‑ассистент в стиле Iron Man: голос, экран, управление ПК, планирование задач, агенты.

---

## Как запустить

**1. Rust‑ядро** (управление Windows: экран, мышь, клавиатура, буфер, процессы):

```bash
cd rust_core
cargo build --release
cargo run --release
```

Оставь окно открытым — сервер слушает `127.0.0.1:50051`.

**2. Python‑ядро** (агенты, речь, зрение, API). В **новом** терминале:

Без `uv` (обычный Python и venv):

```powershell
cd ai_core
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e .
```

Или через зависимости из файла: `pip install -r requirements.txt`.

Один раз сгенерировать gRPC‑стабы (из **корня** репозитория):

```bash
python scripts/generate_proto.py
```

Запуск сервера:

```bash
cd ai_core
python main.py
```

(Если используешь uv: `uv run python -m jarvis_ai.server`.)

Итог: Rust‑ядро на порту **50051**, Python‑API на **http://127.0.0.1:8000**.

**По умолчанию включено постоянное прослушивание микрофона.** Скажи «Привет, Джарвис» или «Джарвис» — ассистент ответит «Слушаю» и выполнит команду (например: «Привет, Джарвис, открой блокнот» → откроется блокнот). Отключить: в `config/config.yaml` задать `voice.always_listen: false`.

**Качество распознавания:** при фоновой музыке/видео Whisper может «додумывать» субтитры — лучше тише окружение или наушники с микрофоном. В `config/config.yaml`: `voice.chunk_seconds` / `tail_seconds` — длина записи; `asr_model: small` точнее, чем `base`; `command_extra_seconds` — доп. время, если команда короткая.

**Первая загрузка Whisper:** модель скачивается с Hugging Face (не в конструкторе `ASR`, чтобы не блокировать сервер). Для лимитов и скорости задайте токен: `setx HF_TOKEN "hf_..."` (создать на [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)). При «зависании» скачивания можно попробовать в PowerShell: `$env:HF_HUB_DISABLE_XET="1"` перед запуском (или уже включено в коде). Таймаут: `voice.asr_load_timeout_sec` в `config.yaml`.

## Как пользоваться

- **Проверка работы:** открой в браузере `http://127.0.0.1:8000/health` — должен вернуться `{"status":"ok"}`.

- **Текстовый ввод (без голоса):** отправь запрос к ассистенту — он пойдёт в планировщик и исполнитель:
  ```bash
  curl -X POST http://127.0.0.1:8000/api/input/text -H "Content-Type: application/json" -d "{\"text\": \"Открой блокнот\"}"
  ```

- **Статус системы:** `GET http://127.0.0.1:8000/api/status` — загрузка CPU, память, батарея (данные из Rust‑ядра).

- **Текст с экрана (OCR):** `GET http://127.0.0.1:8000/api/screen/ocr` — скриншот через Rust, распознавание текста в Python.

- **Голос — запись с микрофона:** записать несколько секунд и получить текст (при наличии «джарвис» в фразе — событие уйдёт в агентов):
  ```bash
  curl -X POST http://127.0.0.1:8000/api/voice/listen -H "Content-Type: application/json" -d "{\"duration_sec\": 5}"
  ```

- **Голос — озвучка ответа:** сказать текст через встроенный TTS:
  ```bash
  curl -X POST http://127.0.0.1:8000/api/voice/speak -H "Content-Type: application/json" -d "{\"text\": \"Привет, я Джарвис\"}"
  ```

Настройки (адрес Rust, токен, DeepSeek, путь к БД): **`config/config.yaml`**. Для работы с Rust‑ядром убедись, что в конфиге указаны те же `grpc_address` и `auth_token`.

## Доступность (голос и экран)

- **Экранный читалка:** скажи «Прочитай экран» или «Что на экране» — JARVIS озвучит текст с экрана по частям. Управление: «Дальше», «Назад», «Стоп», «Повтори».
- **Клик по тексту:** «Нажми кнопку Вход», «Кликни по Отмена», «Выбери Файл» — поиск текста на экране (OCR) и клик по нему.
- **Подтверждение опасных действий:** при запуске установщиков (setup.exe, install и т.п.) JARVIS спросит: «Подтвердите. Скажите «Да» или «Отмена»». Ответ «Да» / «Подтверждаю» — выполнить, «Нет» / «Отмена» — отменить.
- **Локальные ответы без LLM (интернет нужен только для погоды):**
  - **Время:** «Который час», «Сколько времени», «Какое время».
  - **Арифметика:** «Сколько будет 2 плюс 2», «Посчитай 17 умножить на 3» (цифры и знаки `+ - * / ( )`).
  - **Погода (Open-Meteo, без API-ключа):** «Какая погода», «Погода в Москве», «Погода в Санкт-Петербурге».
  - **Папка на рабочем столе:** «Создай папку Тест», «Создай папку Работа на рабочем столе».
- **Команды по голосу:** «Открой блокнот», «Открой браузер», «Введи текст привет», «Прокрути вниз» (прокрутка пока без реализации в Rust). Распознавание интентов — по ключевым фразам в `jarvis_ai/intents/detector.py`.
- **Приветствие после активации:** после «Привет, Джарвис» звучит «Слушаю. Говорите команду.» — можно сразу назвать действие.

## Клонирование и публикация на GitHub

1. **Создай репозиторий** на [github.com/new](https://github.com/new) (без README, если уже есть локальный проект).

2. **В папке проекта** (если ещё не инициализирован git):

```powershell
cd C:\Users\admin\Desktop\AIWin
git init
git add .
git commit -m "Initial commit: JARVIS for Windows"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПО.git
git push -u origin main
```

3. **Секреты** (ключи API, токены) не коммить — в репозитории есть `.gitignore` для `.venv` и `.env`. Пример переменных: `.env.example`.

4. При **SSH** вместо HTTPS:

```powershell
git remote add origin git@github.com:ВАШ_ЛОГИН/ИМЯ_РЕПО.git
git push -u origin main
```
